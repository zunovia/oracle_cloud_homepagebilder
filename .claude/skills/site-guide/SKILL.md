# サイトデザインガイド

## カラーパレット
- Primary: `#C41E3A` (St. John's Red)
- Primary Dark: `#9B1830`
- Dark: `#0D0D0D`
- Dark Secondary: `#1A1A2E`
- Light: `#F7F7F7`
- Text: `#2D2D2D`
- Text Light: `#6B6B6B`

## タイポグラフィ
- 見出し: Montserrat (300-800)
- 本文: Montserrat + Noto Sans JP (日英対応)
- レタースペーシング: 見出しは広め (2-6px)、本文は標準

## デザイン原則
- WIX風のクリーンでミニマルなデザイン
- 余白を十分に取る
- スクロールアニメーション（フェードイン）
- ホバーエフェクトでインタラクティブ感
- モバイルファースト・レスポンシブ

## ページ構成
1. Home (Hero + Highlights)
2. About (プロフィール + 情報)
3. Career (タイムライン + 成績表)
4. Gallery (写真グリッド)
5. Contact (フォーム + SNS)
