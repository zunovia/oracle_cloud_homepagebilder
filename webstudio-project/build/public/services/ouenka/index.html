ご依頼の例使われる場面
企業の応援歌・社歌周年行事やキックオフでの披露、朝礼、採用説明会の動画
スポーツチームの応援歌試合前のベンチ、応援席での合唱、卒団式・引退試合
店舗のテーマソング店内 BGM、SNS の動画、イベントでの店頭演出

共通しているのは、みんなで同じ言葉を口にする場面があることです。 聞き取りでいただいた言葉を、できるだけそのまま歌詞に残します。 「うちの言葉だ」と思える歌になるかどうかは、そこで決まります。

なぜ3曲なのか

歌詞を1本に決めてから、曲調だけを変えて3曲つくります。 比べるのが曲調だけなので、社内やチームで「どれにする？」を決めやすくなります。 歌詞も曲も3案ずつだと、組み合わせが多すぎて決まりません。

たとえば企業の応援歌なら、キックオフ用の明るいロック、式典用の行進曲、採用動画に流すアコースティック、というように、 使う場面ごとに1曲ずつ持っておく使い方もできます。

進め方

  • 1. お申し込み — フォームに、用途と、歌に入れたい言葉を分かる範囲でご記入ください。
  • 2. 聞き取り（オンライン30〜60分） — 合言葉、大事にしていること、現場の様子、参考にしたい曲の雰囲気をお聞きします。
  • 3. 歌詞のご確認 — 歌詞をお送りします。ここで言葉を直していただけます。
  • 4. 3曲のお届け — 確定した歌詞で、曲調の違う3曲をお届けします。
  • 5. 手直し — プランに応じた回数まで、歌詞の修正と曲のつくり直しをお受けします。

お申し込みから3曲のお届けまで、目安は2週間ほどです。行事の日が決まっている場合は、お申し込み時にお知らせください。
