Windows Tool

台本と画像を用意するだけ。
ナレーション付きの動画ができる。

Markdownで書いた台本と、スライド画像を並べておく。それだけで、 読み上げ音声つきのMP4動画が自動で組み上がります。 研修資料や手順の説明を動画にしたいけれど、編集ソフトを覚える時間がない—— そんな場面のために作ったツールです。

Windows ブラウザで操作 無料・オープンソース
GitHub で入手

使い方は4ステップ

  • 1. セットアップ — install.bat をダブルクリック。Python・FFmpegの確認から、必要なパッケージの導入までを自動で行います。初回だけの作業です。
  • 2. 起動 — start.bat をダブルクリックすると、ブラウザが開いて操作画面が表示されます。コマンド入力は不要です。
  • 3. 素材を置く — 台本を input/script.md に書き、スライド画像を input/images/ にファイル名順で並べます。
  • 4. 生成 — ブラウザ上で「動画生成」を押すと、完成した動画が output/ に出力されます。

黒い画面（コマンドプロンプト）を触る必要はありません。バッチファイルのダブルクリックと、ブラウザ操作だけで完結します。

こんな場面に

  • 社内研修や手順書を、読むものから見るものに変えたいとき
  • スライドは作ったが、ナレーションを録る時間が取れないとき
  • 内容を更新するたびに、動画を作り直す必要があるとき（台本を直して再生成するだけで済みます）

必要なもの用途
Windows動作環境
Python 3.10以上アプリの実行環境
FFmpeg動画と音声の結合処理

Python と FFmpeg は install.bat が有無を確認して案内します。 音声合成に外部サービスを使うため、台本のテキストはそのサービスへ送信されます。 機密性の高い内容を扱う場合はご留意ください。
