ボイテキ プライバシーポリシー

最終更新日: 2026年9月8日

本ポリシーは、Androidアプリ「ボイテキ」（以下「本アプリ」）における情報の取り扱いについて定めるものです。本アプリは、一般社団法人サーコミュニケーション（Sur Communication Inc.、以下「当方」）が提供する音声入力キーボードです。

1. 基本方針

当方は、利用者の個人情報および入力内容を一切収集・保存・送信しません。

  • 本アプリには、広告・アクセス解析・クラッシュレポート等のサードパーティSDKが含まれていません。
  • 当方が管理するサーバーへの通信はありません。
  • アカウント登録は不要です。

2. 本アプリが行うこと

本アプリは Android の入力方法（IME／キーボード）として動作します。利用者がマイクボタンを押している間だけ音声を取得し、それを文字に変換して、利用者がカーソルを置いている入力欄に挿入します。

3. 音声の取り扱い

音声は、利用者がマイクボタンを押している間のみ取得されます。取得した音声の送信先は、利用者が選択している音声認識エンジンによって異なります。

いずれの場合も、音声は文字への変換のためだけに使われ、本アプリが端末内に音声ファイルを保存することはありません。

  • 端末標準の音声認識の取り扱いについては、端末メーカーおよび音声認識提供元（多くの場合 Google）のプライバシーポリシーが適用されます。
  • Groq Whisper は、利用者ご自身が API キーを入力した場合にのみ動作します。この場合、Groq, Inc. のプライバシーポリシーおよび利用規約が適用されます。

4. 入力内容（キーボードとして見える文字）の取り扱い

本アプリは Android の入力方法として動作するため、技術的には利用者が入力欄に入れた文字にアクセスできる立場にあります。

本アプリは、この文字情報を記録・保存・送信しません。

文字情報は、以下の目的のためだけに、その場で参照されます。

  • 「1文字消す」「全部消す」「取り消す」「コピー」の各操作を正しく行うため
  • 変換結果を正しい位置に挿入するため

本アプリは、入力履歴・学習辞書・変換履歴の類を一切保持しません。かな漢字変換の辞書はアプリに同梱された固定の辞書であり、利用者の入力によって書き換わることはありません。また、パスワード欄など秘匿性の高い入力欄では、音声入力の機能自体を無効にしています。

5. 端末内にのみ保存される情報

以下の設定は、お使いの端末内（アプリ専用の保存領域）のみに保存されます。

  • 文字の整えかたの設定（フィラー除去・句読点補完などの ON/OFF）
  • マイクの表示位置
  • 音声認識エンジンの選択
  • さいきん使った絵文字
  • 利用者が入力した Groq API キー（入力した場合のみ）

これらは当方に送信されません。また、クラウドバックアップおよび端末間データ転送の対象外に設定しており、アプリを削除すると同時に消去されます。

7. 第三者提供・共有

当方は、利用者に関するいかなる情報も第三者へ提供・販売しません。本アプリを通じた情報の第三者への送信は、第3項に記載した音声認識エンジンへの音声送信に限られます。

8. 子どもの利用について

本アプリは特定の年齢層を対象としていませんが、13歳未満の子どもから意図的に情報を収集することはありません（そもそも情報を収集しません）。

9. 改定について

本ポリシーを変更する場合は、本ページの最終更新日を改めた上で掲載します。重要な変更がある場合は、アプリの更新情報でお知らせします。

English Summary

Voiteki is a Japanese voice-input keyboard for Android. It does not collect, store, or transmit any text you type or dictate. There are no ads, no analytics, and no crash-reporting SDKs, and the app never communicates with any server operated by us. Audio is captured only while you hold the microphone button and is sent only to the speech-recognition engine you have selected: your device's built-in recognizer (default) or, if you supply your own API key, Groq Whisper. Settings are stored on your device only, excluded from cloud backup, and deleted when the app is uninstalled. Voice input is disabled in password fields. The app does not use an AccessibilityService.
