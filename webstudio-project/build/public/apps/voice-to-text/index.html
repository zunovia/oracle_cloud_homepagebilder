キーを押して話すだけ。
どのアプリにも、文字が入る。

F2 を押して話し、もう一度押す。それだけで、文字起こしとAI校正を終えたテキストが カーソルのある場所にそのまま入ります。 Chrome・Word・VS Code・Slack など、アプリを選びません。

高性能音声入力ソフトがほぼ無料で使えます！

できること

  • どのアプリでも使える — 専用の入力欄はありません。カーソルがある場所に直接入るので、ブラウザでも文書でも、チャットでも同じように使えます。
  • 速い — 変換はおよそ0.3〜0.5秒。マイクは常に待機状態なので、押した瞬間に録音が始まります。
  • AI校正 — 句読点をつけ、言い淀みを消し、文脈から誤変換の漢字も直します（成形→整形、機械→機会 など）。
  • ユーザー辞書 — よく使う固有名詞や専門用語を登録しておくと、認識の精度が上がります。
  • 音声コマンド — 「エンター」で改行、「まる」で句点、「かぎかっこ」で「」など、声だけで記号が打てます。
  • フローティングボタン — 画面の隅に小さなボタンが常駐します。クリックでも録音でき、ドラッグで好きな位置へ動かせます。
  • 転写履歴 — 直近20件を保存。貼り付けに失敗したときも、履歴からコピーし直せます。

使い方

  • 1. F2 を押す → 録音が始まります
  • 2. 話す
  • 3. もう一度 F2 を押す → 文字起こしとAI校正を経て、カーソル位置に挿入されます

画面右下のボタンをクリックしても、F2 と同じように操作できます。

導入手順

  • 1. ダウンロード — 最新リリースから ZIP を取得します。
  • 2. 展開して install.bat を実行 — 任意のフォルダに展開し、install.bat をダブルクリック。デスクトップにショートカットが作られます。
  • 3. Groq APIキーを入力 — 初回起動時に入力画面が出ます。取得方法は下記のとおりです。

Windowsの警告（SmartScreen）が出た場合は「詳細情報」→「実行」を選んでください。初回のみです。

Groq APIキーについて（無料・約3分）

このアプリを使うには、ご自身で無料のGroq APIキーを取得していただく必要があります。 音声認識と文章校正の処理を Groq のサービスで行うためです。

  • console.groq.com にアクセス
  • Googleアカウント等でサインアップ（クレジットカード不要）
  • 左メニューの「API Keys」→「Create API Key」
  • 表示されたキーをコピーし、アプリの初回画面に貼り付け

無料枠は音声認識 2,000回/日、文章校正 14,400回/日です。個人利用であれば実質無料で使えます。

ご利用にあたって

音声は文字起こしのため Groq のサービスへ送信されます。 機密性の高い内容を扱う場合は、この点をご確認のうえご利用ください。 APIキーはお使いのPC内にのみ保存され、当法人が取得することはありません。

本アプリはオープンソースとして公開しています。何をしているかはソースコードで確認できます。 不具合のご報告や改善のご提案は、GitHub の Issue またはメールでお寄せください。
