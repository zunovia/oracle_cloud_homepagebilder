Security ／ 個別導入

その映像は、
どこを通っていますか。

市販のネットワークカメラの多くは、映像をいったんメーカーのクラウドに預け、そこを経由してスマホに届けます。 設置が簡単な代わりに、映像は自分の建物の外を通ります。 SafeCam は、その経路そのものを作り替える仕組みです。 安価な市販カメラをそのまま使いながら、映像をLANの中だけで完結させ、 カメラからインターネットへの出口を塞ぎます。

問題は「どこの製品か」ではなく「どこを通るか」

カメラの安全性は、メーカーの国籍で決まるものではありません。 決めているのは映像がどの経路を通るか、ただそれだけです。 同じメーカーの製品でも、クラウド経由でしか見られない機種と、 設定次第でLAN内だけで完結する機種があります。

そして経路を確かめるための判断材料は、たった2つしかありません。

  • 1. カメラから直接、映像を受け取れるか — RTSP / ONVIF という業界標準に対応していれば、メーカーのアプリを介さずに映像を取り出せます。
  • 2. インターネットを切っても動くか — 外部との通信を止めた状態で映像が映り続けるなら、その映像は外に出ていないと確認できます。

SafeCam は、この2つを満たすカメラを選び、 「実際にインターネットを遮断した状態で運用する」ところまでを含めた構成です。 設定の話で終わらせず、通信経路そのものを塞ぎます。

SafeCam がやっている4つのこと

  • ローカル視聴 — スマホのアプリがカメラへ直接つなぎ、映像を表示します。メーカーのクラウドもアカウントも経由しません。カメラの向き（PTZ）の操作も同じ経路で行います。
  • 連続録画 — 手のひらサイズの小型コンピューターを1台置き、24時間の映像を保存し続けます。古いものから自動的に消える方式なので、容量の管理も要りません。
  • 遠隔視聴 — 外出先から見たい場合は、その拠点のネットワークに暗号化された経路で入り、あらためて「LANの中から」映像を見ます。映像をインターネット上のサーバーに置くことはありません。
  • インターネット遮断 — カメラが外部と通信しようとしても届かないよう、ネットワーク側で出口を塞ぎます。カメラ本体の設定に頼らず、物理的な経路として遮断するのが要点です。

カメラそのものは市販品をそのまま使います。特別な機材を購入していただく必要はありません。

費用は、その場で分かります

「見積もりを取らないと分からない」という状態をなくしました。 必要なものは録画機・電源類・ソフトウェア・カメラの4つだけです。 変わるのはカメラを何台にするかと何機種使うかの2つだけで、 選べばその場で総額が出ます。

この構成で相談する

金額はすべて税抜です。 ソフトウェアが機種ごとの費用になっているのは、カメラの機種によって接続方法や設定手順が変わり、 機種ごとに対応が必要なためです。同じ機種で揃えれば、台数が増えてもここは20,000円のままです。 録画機に幅があるのは、設置環境によって必要な性能が変わるためです。 カメラをご自身で用意される場合は、対応する機種と設定手順をお伝えします。 2拠点以上をご希望の場合は、拠点ごとに録画機と電源類が必要になりますので、個別にお見積りします。 上記は概算です。正式なお見積りは、設置環境をうかがったうえでお出しします。

カメラは3種類に分かれます

購入前に見分けがつくよう、クラウドからどれだけ独立できるかで整理しています。 SafeCam で使えるのは ② と ③ です。

種類特徴SafeCam
① クラウド専用 RTSP / ONVIF に対応せず、メーカーのアプリでしか映像が見られない。ネットを切ると映らなくなる 使えません
② ハイブリッド 出荷時はクラウド前提だが、設定で RTSP / ONVIF を有効化できる。初期設定のときだけネットが必要 主にこの種類を使います
③ 標準対応機 最初から RTSP / ONVIF が有効。業務用に多く、価格は高め 最も素直に使えます

安価な家庭用カメラのほとんどは ② です。 つまり「高いカメラを買わないと安全にならない」わけではありません。 4,000〜5,000円程度の製品でも、選び方と設定次第でLAN内に閉じ込められます。

向いている場面／向いていない場面

  • 向いている — 事務所・作業場・倉庫・自宅など、室内の見守り。図面や試作品、個人情報を扱う部屋で、映像を外部に預けたくない場合。留守宅やご実家の様子の確認。
  • 向いていない — 屋外の常時監視（防水・夜間性能を含めた設計が別途必要です）。警備会社のような駆けつけ対応や24時間の有人監視。証拠能力を厳密に担保する用途。

なお、人が映る場所にカメラを設置する場合は、撮影範囲の告知や記録の取り扱いについて、 設置される側でのご配慮が必要です。運用ルールづくりも含めてご相談いただけます。
