第4条（料金・アプリ内課金）

  1. 本アプリは無料で利用できます。一部の本アプリには、追加の機能や広告の非表示を購入できるアプリ内課金（買い切り、または定期購入）があります。対象と価格は、各アプリの画面と Google Play に表示します。
  2. アプリ内課金の購入、支払い、返金は、Google Play の利用規約および返金に関するポリシーに従って、Google を通じて行われます。提供者は、利用者のクレジットカード情報等の決済情報を取得しません。
  3. 定期購入は、利用者が解約しない限り、期間ごとに自動で更新されます。解約は、Google Play の「定期購入」の画面から行えます。解約しても、すでに支払った期間の終わりまでは利用できます。

  5. 本アプリの利用にかかる通信料と、利用者が自分で契約する外部のサービス（音声認識・音声合成・AI の API 等）の利用料は、利用者の負担となります。

第5条（広告）

一部の本アプリには、広告配信事業者（Google AdMob 等）を通じて広告が表示されます。広告の内容や、広告から移動した先の商品・サービスについては、それぞれの広告主が責任を負います。

第7条（健康・安全に関する注意）

  3. 歩きながら、または周囲の安全を確かめないまま本アプリを操作しないでください。

第16条（アプリごとの補足条項）

次の条項は、それぞれのアプリにだけ適用されます。

パシャ採寸

  • 採寸の値は、写真と A4 用紙をもとに推定した目安です。服の置き方、しわ、撮影の角度等によって誤差が生じます。フリマ等に出品する前に、必要に応じてメジャーで確かめてください。
  • 本アプリの採寸の値を使った出品や取引で生じたトラブルは、利用者と取引の相手方の間で解決してください（第12条第4項）。
  • 「広告を削除」は買い切りのアプリ内課金です（第4条）。

CamTally

  • カウントや計測の値は、AI による自動の検出にもとづく目安です。人の多い場面、暗い場面、隠れや重なりがある場面等では、数え漏れや数えすぎが生じます。
  • 人を撮影・録画するときは、撮影する場所のルールに従い、撮影される人の肖像権やプライバシーに配慮してください。
  • 避難誘導、入場者数の法令上の管理等、安全や法令に関わる計測の唯一の手段として使わないでください。

センタリン

  • センタリング（余白の比率）の値は、写真から求めた目安で、誤差の幅を含みます。鑑定・グレーディング会社の評価を予想・保証するものではありません。
  • カードの売買や鑑定に出すかどうかの判断は、利用者の責任で行ってください。
  • センタリン Pro は買い切りのアプリ内課金です（第4条）。

Choppiri

  • 習慣の量の提案は、記録をもとにした目安です。体に負担がかかる習慣（運動、食事等）は、無理のない範囲で、必要に応じて専門家に相談しながら行ってください。
  • Choppiri Pro には、買い切りと年額（自動で更新される定期購入）があります（第4条）。

Cotext

  • 音声認識、読み上げ、翻訳の結果には誤りが含まれることがあります。医療、法律、緊急時など、誤りが重大な結果につながる場面では、筆談や通訳等のほかの手段も併せて使ってください。
  • 会話の相手の声を文字にするときは、相手に配慮し、必要に応じて了承を得てください。

現場ポケット5S診断

  • AI による診断と改善プランは参考情報です。労働安全衛生に関する点検や、法令・社内規程で定められた確認の代わりにはなりません。
  • 写真を撮るときは、機密情報や人が写り込まないよう配慮し、撮影する場所の規程に従ってください。

Luckarise

  • 本アプリは 18 歳以上の方を対象としています。
  • 本アプリは、気持ちに気づき、短い言葉にするための習慣の道具です。心の病気の診断や治療、カウンセリングを行うものではありません。つらい気持ちが続くときは、医療機関や公的な相談窓口に相談してください。
  • 広告をオフにする買い切りのアプリ内課金があります（第4条）。

SeeWalk

  • 歩く速さ、テンポ、歩はば、歩数等の値は目安です。医療機器ではなく、健康状態の診断には使えません（第7条）。
  • 測るときは、周りに障害物のない安全な場所で、転ばないよう注意して歩いてください。

成分レンズ

  • 成分レンズには、アプリ専用の利用規約があります。本規約と内容が異なる場合は、成分レンズの利用規約が優先します（第1条第2項）。
  • 成分の読み取り・照合の結果には、誤りや見落としがありえます。使ってよいかどうかは、必ずパッケージの表示を確かめ、必要に応じて医師・薬剤師等に相談してください。

TABrec

  • TAB 譜・5 線譜は、録音から自動で作った目安です。音の高さ、リズム、和音に誤りが含まれることがあります。
  • 他人の楽曲を録音して作った譜面を公開・配布する場合は、著作権者の許諾等が必要になることがあります。利用者の責任で確かめてください。
  • TABrec Pro は買い切りのアプリ内課金です（第4条）。

ボイテキ

  • 音声の認識には誤りが含まれることがあります。送信や保存の前に、入った文字を確かめてください。
  • パスワード等、人に聞かれたくない内容は、声で入力しないでください。

Voxna

  • エネルギー、明瞭度、表現の幅、テンポ等の指標は、声の録音から求めた目安です。医療機器ではなく、病気の診断には使えません（第7条）。

Voice to Text

  • 本アプリの利用には、利用者が自分で取得する外部の API キー（Groq 等）が必要です。API キーの管理、API の利用料、API の利用規約の遵守は、利用者の責任となります。
  • 文字起こしと校正のため、音声と文字が API の提供者に送られて処理されます。送られた情報の扱いは、API の提供者の規約とプライバシーポリシーに従います。

紙芝居動画ジェネレーター

  • 音声合成等の外部の API を使う場合、その利用料と利用規約の遵守は利用者の負担・責任となります。
  • 利用者が用意した台本・画像、および作成した動画の内容と権利の処理は、利用者の責任となります。

TechFeed Daily

  • 記事の要約は、AI が自動で作成したもので、誤りや抜けが含まれることがあります。正確な内容は、リンク先の元の記事で確かめてください。
  • 元の記事の著作権は、それぞれの配信元に帰属します。

SafeCam

  • SafeCam は一般公開しておらず、個別のご相談・導入支援として提供します。提供の条件は、個別に締結する契約に定め、その契約が本規約より優先します（第1条第3項）。
