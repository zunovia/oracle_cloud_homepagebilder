Voice Accessibility

話した言葉が、
その場で文字になる。

Cotextは、聴覚に障害のある方と聞こえる方のコミュニケーションを支える音声バリアフリーアプリです。 話した内容をリアルタイムで文字にし、入力した文字を声で読み上げます。 声を聞き取りにくい方も、声を出しにくい方も、同じ画面で会話ができます。

アカウント登録不要 会話履歴は端末内 無料 ／ 広告あり

できること

  • リアルタイム音声認識 — 話した言葉がその場でテキストに変換され、画面に表示されます。聞き取りにくい場面でも、会話の内容を目で追えます。
  • テキスト読み上げ — 入力した文章を自然な音声で読み上げます。声を出しにくいときも、文字を打てば相手に声で伝わります。
  • 翻訳 — テキストを多言語に翻訳します。言語が違う相手とのやりとりにも使えます。
  • 会話履歴 — やりとりの内容は端末内に保存され、後から見返せます（最大100件）。

プライバシーへの考え方

音声データはリアルタイムの処理にのみ使われ、サーバーに保存されることはありません。

会話履歴と設定は、すべてお使いの端末内にのみ保存されます。 アプリをアンインストールすると、これらのデータはすべて削除されます。 アカウント登録も不要です。詳細は プライバシーポリシー をご覧ください。
