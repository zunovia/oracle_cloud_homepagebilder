Claudeと一緒に作りました。

Claude（クロード）は、Anthropic社が開発した対話型のAIです。 当法人では、コンサルティングの実務からアプリ開発、日々の情報収集まで、 実際に業務の中心で使っています。 ここでは「何ができるか」ではなく、私たちが実際に何に使っているかをご紹介します。

Claude を使ってみる 料金プランを見る（公式）

当法人での使い方

  • 経理業務の工数を87.5%削減 — 手作業だった伝票入力・仕分け・チェックを、月40時間から月5時間に。導入事例としてサービスページで紹介しています。
  • Androidアプリ6本の開発 — 公開中のアプリは、設計から実装、ストア申請の準備まで Claude と進めました。専任のエンジニアがいない小さな法人でも、動くものを作れています。
  • この法人サイトの構築 — いま見ていただいているページも、Claudeと一緒に作っています。
  • テックニュースの自動配信 — 海外の技術記事を毎朝、日本語に要約して配信する仕組みを動かしています。要約はClaudeが行っています。

私たちが評価している点

  • 長い文章を読ませても崩れにくい — 仕様書や帳票のような、まとまった量の資料を扱う仕事に向いています。
  • 「分からない」と言ってくれる — 曖昧な指示に対して、それらしい答えを作らずに確認を返してくることがあります。業務で使ううえでは、この性質が助かります。
  • そのまま使える文章を書く — 手直しの前提が少なく、業務文書やマニュアルの下書きとして実用に足ります。

ただし万能ではありません。数値の扱いや最新情報は誤ることがあるため、当法人では必ず人が確認する工程を残す前提で組み立てています。

料金について

無料でも使えます。まずは無料の範囲で試してみて、物足りなければ有料プランを検討する、という順番で十分だと思います。

金額はこのページには記載しません。プランも価格も変わるため、古い情報を載せるとかえって迷惑になるからです。 最新の料金はAnthropic公式の料金ページでご確認ください。

導入のご相談も承ります

「入れてみたいが、何から手をつければいいか分からない」という段階のご相談が、いちばん多いです。 当法人は4M（人・設備・材料・方法）を変えずに、業務のすき間にAIを挟むという進め方をしています。 今のやり方を壊さずに始められるので、現場の抵抗も小さく済みます。

リンクについて

このページのボタンは紹介リンクです。ここから登録された場合、当法人に紹介特典が入ることがあります。

特典の有無にかかわらず、お客様のお支払い額が増えることはありません。 また当法人はAnthropic社とは資本関係も業務提携もなく、内容は自分たちで実際に使ったうえでの評価です。 紹介リンクを使いたくない場合は、claude.ai から直接どうぞ。
