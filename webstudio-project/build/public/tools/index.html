紹介リンクについて

各ページのリンクには紹介リンクが含まれます。そこから申し込まれた場合、当法人に紹介特典が入ることがあります。

ただし、お客様のお支払い額が増えることはありません。 Google Workspace については、むしろ紹介リンク経由の方が初年度10%安くなります。 いずれの提供元とも資本関係・業務提携はなく、掲載しているのは自分たちで実際に使っているものだけです。 紹介リンクを使いたくない場合は、各ページに公式サイトへの直接リンクも用意しています。
